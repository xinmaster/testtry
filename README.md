# testtry：基础电路计算器

使用 C11 编写的命令行电路计算器，提供中文菜单，支持欧姆定律和电阻串联、并联计算。程序使用标准 C 库，无需第三方依赖。

## 编译与运行

需要 GCC 和支持 UTF-8 的终端。在项目目录执行：

```sh
gcc -std=c11 -Wall -Wextra -Wpedantic -Werror -O2 circuit_calculator.c -o circuit_calculator
./circuit_calculator
```

也可以使用 Make：

```sh
make
./circuit_calculator
```

`make clean` 删除生成的可执行文件。

## 菜单与操作方法

输入菜单编号并按回车，然后按提示逐行输入数值。一次计算完成后会返回菜单，可以继续计算。

| 编号 | 计算项目 | 依次输入 |
| --- | --- | --- |
| `1` | 电压 | 电流 I、电阻 R |
| `2` | 电流 | 电压 V、电阻 R |
| `3` | 电阻 | 电压 V、电流 I |
| `4` | 串联等效电阻 | 电阻数量、各个电阻值 |
| `5` | 并联等效电阻 | 电阻数量、各个电阻值 |
| `0` | 退出 | 无 |

单位统一为伏特（V）、安培（A）、欧姆（Ω）。输入时只写数值，不写单位；例如 `0.02` 表示 0.02 A，`1e3` 表示 1000 Ω。程序支持小数、科学计数法以及数值前后的空白。

例如计算电压，依次输入：

```text
1
2
5
0
```

其中 `1` 选择电压计算，`2` 是电流，`5` 是电阻，程序显示 `计算结果：10 V`；最后的 `0` 退出。

其他示例：

| 项目 | 输入值 | 结果 |
| --- | --- | --- |
| 电流 | V = 12 V，R = 4 Ω | 3 A |
| 电阻 | V = 12 V，I = 2 A | 6 Ω |
| 串联 | 100 Ω、200 Ω、300 Ω | 600 Ω |
| 并联 | 100 Ω、200 Ω | 66.66666667 Ω |

Linux/macOS 终端也可以通过输入结束符（通常为空行时按 `Ctrl+D`）退出。在任何输入提示处到达文件末尾（EOF），程序都会正常结束。

## 计算公式与适用范围

本程序用于理想电阻电路的基础计算。电压和电流按非负幅值输入，不表示参考方向；不支持交流阻抗、相位或负电阻。

| 项目 | 公式 | 输入条件 |
| --- | --- | --- |
| 电压 | V = I × R | I ≥ 0，R ≥ 0 |
| 电流 | I = V / R | V ≥ 0，R > 0 |
| 电阻 | R = V / I | V ≥ 0，I > 0 |
| 串联 | R总 = R₁ + R₂ + … + Rₙ | 各电阻 ≥ 0 |
| 并联 | 1 / R总 = 1 / R₁ + 1 / R₂ + … + 1 / Rₙ | 各电阻 > 0；存在 0 Ω 时按短路处理，R总 = 0 |

欧姆定律描述理想电阻两端电压、电流和电阻的关系，已知其中两个量即可求第三个。串联时各电阻电流相同、压降相加，因此电阻值相加；并联时各支路电压相同、电流相加，因此电阻的倒数相加。

串并联电阻数量必须是 `1` 到 `1000` 的整数。电阻允许为零，但作为除数时必须大于零；计算电阻时电流也必须大于零。

并联计算使用与上述公式等价的形式：令 `m` 为最小正电阻，计算 `R总 = m / Σ(m / Rᵢ)`。每个比值不超过 1，可以避免直接计算 `1 / Rᵢ` 时出现不必要的数值溢出。零欧电阻在使用这个公式前单独处理。

## 错误输入与数值精度

以下输入会显示错误，并要求重新输入当前项目：

- 空行、文字、数值后附带单位或其他多余字符。
- 非整数的菜单编号或电阻数量，以及超出允许范围的编号或数量。
- 负数、用作除数的零、`NaN`、无穷大或 `strtod` 报告范围错误的数值（包括过大、过小的数值）。
- 超过 255 个字节（不含换行符）的输入行，或包含空字符的输入行。程序会读完该行，避免剩余内容影响下一次输入。

若输入有效，但计算结果溢出为非有限值，或应为正数的结果下溢为零，程序会报告计算错误并返回菜单。

程序使用 `double`，按 `%.10g` 显示结果，即最多 10 位有效数字；较大或较小的结果可能采用科学计数法。浮点数存在舍入误差，极大和极小数值混合计算时，较小项的贡献可能无法保留，因此结果应按有限精度的近似值理解。

## 主要代码及原理

核心代码在 `circuit_calculator.c` 中：

- `main` 显示菜单并分派计算项目，直到用户选择退出或输入结束。
- `read_line` 读取完整的一行，检查行长度及空字符，避免输入残留。
- `read_integer` 与 `read_number` 分别使用 `strtol` 和 `strtod` 转换输入，结合结束指针、`errno`、`isfinite` 和取值范围检查，确认整行都是合法数值后才进行计算。
- `calculate_ohm` 根据菜单选择执行乘法或除法；先检查除数，避免除零。
- `calculate_resistors` 读取电阻数量及各个电阻值，串联时累加，并联时处理短路并使用缩放公式计算。
- `print_result` 检查结果的有效性，再统一输出数值和单位。

输入处理与计算步骤分开，使非法输入可以在当前提示处重试，也使公式和边界条件容易检查。

## 测试

自动化测试需要 Python 3，仅使用标准库。测试会实际启动编译后的 C 程序，通过标准输入提供数据，再检查退出码和输出：

```sh
make test
```

也可以指定 Python 解释器，或直接运行测试脚本：

```sh
make test PYTHON=python3
python3 tests/test_calculator.py ./circuit_calculator
```

测试覆盖五种计算、连续操作、零欧电阻、非法输入后的恢复、数量边界、长行清理、EOF，以及浮点数溢出、下溢和并联极值。

已在 Linux、GCC 14.2.0 环境实际验证：严格编译检查通过，37 项自动化测试全部通过；使用 AddressSanitizer 和 UndefinedBehaviorSanitizer 编译后，同样通过全部测试，未报告异常。交互运行也确认了上面的五种计算示例及除零后的重新输入。

可按以下方式复现运行时检查：

```sh
gcc -std=c11 -Wall -Wextra -Wpedantic -Werror -O1 -g \
    -fsanitize=address,undefined -fno-omit-frame-pointer \
    circuit_calculator.c -o /tmp/testtry-circuit-sanitized
python3 tests/test_calculator.py /tmp/testtry-circuit-sanitized
```
